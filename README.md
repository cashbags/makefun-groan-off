## The joke

> I told the fridge to chill, and now it won't stop giving me the cold shoulder.

78 characters, one line, chosen by a pairwise self-judge tournament over 10
candidate dad jokes against the brief's five criteria (see DESIGN.md).

## How it runs

`main.py` writes the line to `/output/entry.txt`. No network, no randomness,
no reads outside this repository — the same bytes every run.

```sh
python3 main.py   # writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```
